# EFA-audio

Audio de la teoría de [EFA](https://github.com/DkRunker/EFA): un MP3 por lección, publicado como
assets de la release `v1` para reproducirlo desde la web. El código y el texto viven en ese repo.

## Créditos y licencia

- **Voz sintética** generada con el modelo [OmniVoice](https://huggingface.co/k2-fsa/OmniVoice)
  (k2-fsa) mediante VoiceStudio. Licencia del modelo: **CC BY-NC**, además de los términos de
  Higgs Audio 2 y Meta Llama 3. Este audio es solo para uso **no comercial**.
- Parte del Módulo 1 (macroeconomía) está adaptada de **OpenStax**, *Principles of Economics*,
